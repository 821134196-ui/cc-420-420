# 楼宇门禁卡发放与离场回收系统

管理楼栋、租户、人员、门禁卡、权限组、有效期限、临时卡、挂失与回收记录的一体化台账系统。
纯 Python 标准库实现（`sqlite3` + `http.server`），**无需安装任何依赖**。

## 一条命令本地启动

```bash
cd access-control
python3 run.py            # 初始化 SQLite + 预置发卡/挂失/回收演示数据 + 启动 Web
# 打开 http://127.0.0.1:8088/
```

常用参数：`--reset`（清库重预置）、`--port 9000`、`--no-seed`（空库）。

## 核心业务规则

- **两步发卡**：柜台先建单（占住卡号）→ 核对后第二步激活；卡必须同时绑定**人员 + 权限组**才能激活。
- **权限计算**：按权限组的**楼层矩阵 + 时段 + 生效日期**综合判定，任一不符即拒绝并生成越界事件。
- **离场回收**：人员离场冻结名下全部有效卡并下发吊销；实体卡交回后登记「已回收」终态。
- **挂失**：即时冻结吊销；**挂失卡不能通过补录直接恢复**，只能用新卡补卡换发，新卡保留与旧卡的双向关联，旧卡永久注销。
- **临时卡**：必须填到期时间，进程内守护线程每 10 秒扫描，到期自动失效并吊销。
- **权限修改二次确认**：管理员提交变更单（暂不生效）→ 再次确认后才写库，全程审计。
- **并发唯一发卡**：`BEGIN IMMEDIATE` 事务 + 待确认发卡单占位，同一卡号两个柜台同时发放只允许一笔成功。
- **设备适配器**：在线指令即时送达；设备离线时指令写入发件箱、刷卡本地记录（`synced=0`），恢复在线自动补传并同步。
- **事件**：卡片遗失、损坏、借用转交、权限越界、设备离线/恢复均落事件表。
- **敏感信息**：卡号默认部分遮挡（如 `A-●●●9`），单卡点眼睛或顶部开关按需揭示。

## 界面

白色 / 深石板灰 / 电光蓝主题；楼层权限用简洁矩阵（蓝格＝授权）；门禁卡以顶部**状态色带**区分
可用（绿）、挂失（红）、待回收（琥珀）、损坏（紫）、在库（灰）、已回收/失效。

交付台账：总览、人员台账、门禁卡库存、权限组、发卡回收（两步柜台）、挂失处理、设备与补传、审计查询。

## 目录结构

```
access-control/
├── run.py                  # 单命令启动入口
├── accessctl/
│   ├── db.py               # SQLite schema 与线程安全连接/事务
│   ├── services.py         # 核心领域服务与规则引擎
│   ├── seed.py             # 演示数据（发卡/挂失/替换/离场/回收/离线/临时卡）
│   ├── tasks.py            # 进程内到期扫描守护线程
│   ├── server.py           # HTTP JSON API + 静态资源
│   └── static/             # index.html / styles.css / app.js
└── tests/test_system.py
```

## 主要 API

`POST /api/issues/draft` → `/api/issues/confirm`（两步发卡）、`/api/cards/lost|damaged|replace|recycle|borrow`、
`/api/people/depart`、`/api/groups/change` → `/api/groups/change/confirm`（二次确认）、
`/api/devices/status`（离线/恢复补传）、`/api/access/attempt`（门岗刷卡）、
`/api/tasks/expire`（手动触发到期扫描）；操作员身份经 `X-Operator-Id` 请求头传递。
